# UI Design Instructions

This frontend follows Hallmark design principles.

## Avoid

- Generic Hero → Features → CTA landing pages
- 3-column feature grids
- Cookie-cutter AI SaaS designs
- Fake metrics or testimonials
- Browser mockups
- Overused glassmorphism

## Design Philosophy

POLYNOUS is an AI research platform powered by multiple specialized agents.

The interface should feel:

- Sophisticated
- Editorial
- Premium
- Technical
- Confident

Inspiration:

- Linear
- Apple
- Perplexity
- Vercel
- Notion

## Layout Rules

- Prefer asymmetric layouts
- Use storytelling and narrative flow
- Emphasize whitespace
- Make each page structure unique
- Avoid obvious dashboard patterns

## Typography

- Primary: Geist
- Secondary: Instrument Serif

## Colors

- Background: #0A0A1E
- Accent Green: #00FF0F
- Accent Purple: #A855F7

## When Editing Existing Components

- Preserve the existing design system
- Only redesign if explicitly requested
